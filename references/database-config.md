# 飞书多维表格配置

## 表格信息

**表格名称**：人生笔记
**Base Token**：YOUR_BASE_TOKEN
**表格地址**：YOUR_BASE_URL

---

## 表1：心情感悟

**Table ID**：YOUR_FEELING_TABLE_ID

### 字段配置

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 时间 | 日期时间 | 记录时间 |
| 内容 | 文本 | 感悟内容 |
| 具体事件 | 文本 | 具体发生了什么事 |
| 思考 | 文本 | 当时的思考和分析 |
| 情绪标签 | 多选 | 开心、焦虑、平静、疲惫、困惑、感恩、释然、委屈、愤怒、期待... |
| 场景标签 | 多选 | 人际、工作、生活、成长、关系、独处、家庭... |
| 下次怎么做 | 文本 | 经验总结和改进方向 |

### 操作命令

#### 记录感悟

```bash
lark-cli base +record-upsert \
  --base-token "YOUR_BASE_TOKEN" \
  --table-id "YOUR_FEELING_TABLE_ID" \
  --json '{"时间":"2026-04-17 22:00:00","内容":"感悟内容","具体事件":"具体事件","思考":"思考分析","情绪标签":["焦虑"],"场景标签":["人际"],"下次怎么做":"下次改进"}' \
  --as user
```

---

## 表2：纪念日

**Table ID**：YOUR_ANNIVERSARY_TABLE_ID

### 字段配置

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 纪念日名称 | 文本 | 纪念日名称 |
| 日期 | 日期 | 纪念日日期 |
| 类型 | 单选 | 生日、节日、入职纪念日、其他 |
| 提醒状态 | 文本 | 已提醒/未提醒 |

### 操作命令

#### 添加纪念日

```bash
lark-cli base +record-upsert \
  --base-token "YOUR_BASE_TOKEN" \
  --table-id "YOUR_ANNIVERSARY_TABLE_ID" \
  --json '{"纪念日名称":"家人生日","日期":"2026-04-20","类型":"生日"}' \
  --as user
```

---

## 表3：礼物记录

**Table ID**：YOUR_GIFT_TABLE_ID

### 字段配置

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 礼物内容 | 文本 | 礼物名称 |
| 对象 | 文本 | 送/收对象 |
| 场合 | 文本 | 生日、节日、日常... |
| 日期 | 日期 | 记录日期 |
| 年份 | 数字 | 年份 |
| 花费 | 数字 | 花费金额 |
| 备注 | 文本 | 备注说明 |
| 对方反馈 | 文本 | 对方反馈 |
| 纪念日 | 关联 | 关联到纪念日表 |

### 操作命令

#### 记录礼物

```bash
lark-cli base +record-upsert \
  --base-token "YOUR_BASE_TOKEN" \
  --table-id "YOUR_GIFT_TABLE_ID" \
  --json '{"礼物内容":"鲜花","对象":"家人","场合":"生日","日期":"2026-04-20","年份":2026,"花费":150}' \
  --as user
```

---

## 注意事项

- 心情感悟的情绪标签是**多选**，可以同时有多种情绪
- 场景标签也是**多选**
- 纪念日提醒需要创建3个日程事件（提前7天、提前1天、当天）
- 礼物记录不单独提醒，在纪念日提醒时汇总展示
