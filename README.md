# 人生笔记

> 一个基于扣子(Coze)的个人成长记录 Skill，记录事件、思考、情绪，提供多视角周分析，支持纪念日和礼物管理。

## 项目背景

一个个人成长记录工具，用于记录工作生活中的感悟、情绪，并通过心理学视角进行周分析。

**设计理念**：记录不只是记录，更是自我认知的工具。通过结构化记录和多视角分析，帮助看到行为模式、情绪根源。

## 功能一览

| 模块 | 功能 | 说明 |
|------|------|------|
| 人生笔记 | 记录事件、思考、情绪 | 支持情绪标签、场景标签 |
| 周分析 | 多视角深度分析 | 心理视角、成长视角、行动建议 |
| 纪念日 | 提醒管理 | 提前7天/1天/当天三段提醒 |
| 礼物记录 | 送礼记录 | 关联纪念日，便于回顾 |

## 文件结构


## 技术栈

- **平台**：扣子 (Coze) - AI Agent 开发平台
- **数据存储**：飞书多维表格
- **脚本**：Shell + lark-cli (飞书命令行工具)

## 使用方式

在扣子平台安装此 Skill 后，通过触发词激活：

```
人生，记录：今天和同事讨论方案时起了争执，我觉得自己太冲动了
人生，纪念日：家人生日 4月20日
人生，礼物：一束花 2026 家人生日
人生，查看笔记
人生，周分析
```

## 周分析维度

**心理视角**（专业心理分析）：
- 潜意识动机：行为背后真正的驱动力
- 关系模式：与他人互动中的固定剧本
- 自我概念：如何看待自己、自我价值感
- 防御机制：用什么方式保护自己
- 情绪根源：情绪背后的核心议题
- 成长课题：正在面对的人生阶段任务

**成长视角**：
- 经验沉淀：本周有哪些经验可以复用
- 问题复盘：哪些问题在重复出现
- 进步识别：相比之前是否有改善

**行动建议**：
- 具体可执行的建议
- 「下次怎么做」系统化
